# AutomaticAppVolumeReducer
This python script will set the volume of the apps that are not known to itself to %10, eliminating the deafening scenarios the first time an app or game is launched.

When you run the script, a json file will be created logging all the apps that are currently running in your pc. Apps launched after the initialization will get their volumes reduced to %10. The script will save the apps afterwards so you may adjust the volume however you please. 
I would recommend creating a shortcut in the shell:startup so it launches with every instance of your PC.

This was made for personal use after I almost lost my hearing when I launched Diablo 4 for the first time.
